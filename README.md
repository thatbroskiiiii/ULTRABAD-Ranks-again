### INSTALLATION GUIDE



###### R2modman:

1: Download the skinpack along with the dependencies

2: Open ULTRAKILL and make your way to the "US" button located in the main menu

3: Select "ULTRABAD RANKS" and apply it





###### Manual:

1: Download the skinpack along with the dependencies

2: Run the game once to get all necessary folders and whatnot

3: Make your way to

C:\\Users\\YOURNAME\\AppData\\Roaming\\bobthecorn2000\\ULTRAKILL\\ultraskinsGC-V2\\GlobalSkins

4: drag and drop the "ULTRABAD RANKS" folder into the previous folder mentioned

5: Go back to ULTRAKILL and make your way to the "US" button located in the main menu

6: Select "ULTRABAD RANKS" and apply it
